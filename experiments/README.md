# Experiments

Create one folder per experiment using a sortable ID, for example:

`EXP-001-agent-tool-reliability/`

Each experiment should include:

- `README.md` — question, hypothesis, setup, variables, metrics, results
- `config/` — reproducible settings
- `scripts/` — runnable experiment code
- `results/` — small summarized outputs only

Large datasets, model weights, secrets, and generated artifacts should stay out of Git.
