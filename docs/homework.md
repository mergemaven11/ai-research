# Homework and Review Guide

Complete one homework set per week. Put answers in `reports/week-XX.md` and code in `experiments/week-XX/`.

## Week 1

- Write one falsifiable AI-system hypothesis.
- Create an experiment manifest containing seed, dataset version, model/configuration, environment, and command.
- Reproduce the same run and explain any variation.

**Done when:** a second person can reproduce the run from the README.

## Week 2

- Build majority, count-vector, and TF-IDF baselines.
- Report precision, recall, F1, confusion matrix, and at least five inspected errors.
- Explain why accuracy alone may mislead.

**Done when:** metrics are generated by a tested command, not copied manually.

## Week 3

- Create at least 25 fixed test cases.
- Compare zero-shot, few-shot, and structured-output prompts.
- Categorize failures and recommend one prompt with evidence.

**Done when:** raw results and an aggregate comparison are saved.

## Week 4

- Index a public document set with source metadata.
- Compare two chunking strategies and two top-k values.
- Measure retrieval recall using at least 15 labeled questions.

**Done when:** every retrieved chunk can be traced to its source.

## Week 5

- Build an answer-with-citations flow.
- Add “insufficient evidence” behavior.
- Test answer correctness, citation correctness, and unsupported claims.

**Done when:** the system does not invent an answer for deliberately unanswerable questions.

## Week 6

- Define strict JSON schemas for two read-only tools.
- Add timeout, retry, maximum-step, and maximum-cost controls.
- Draw one threat boundary and explain where human approval is required.

**Done when:** invalid tool calls fail safely and are covered by tests.

## Week 7

- Write a rubric with observable scoring criteria.
- Create a golden evaluation set and regression threshold.
- Compare deterministic and model-graded evaluation; document disagreement.

**Done when:** the evaluation exits nonzero on a known bad version.

## Week 8

- Add correlation IDs and structured event logs.
- Measure p50/p95 latency, error rate, and approximate cost.
- Inject a timeout or dependency failure and verify the fallback.

**Done when:** one trace reconstructs the complete request path without exposing sensitive content.

## Week 9

- Create at least 20 safe red-team cases across four threat categories.
- Document attack, expected defense, actual result, and residual risk.
- Add a regression test for each fixed weakness.

**Done when:** the report clearly separates prevented, detected, and unresolved attacks.

## Week 10

- Create a validated FastAPI endpoint, health check, and Dockerfile.
- Add unit and integration tests.
- Verify configuration comes from environment variables and secrets are absent from the image.

**Done when:** a fresh `docker build` and container smoke test pass.

## Week 11

- Add CI jobs for formatting/linting, tests, evaluation, and container build.
- Generate dependency or SBOM evidence.
- Write a rollback runbook and simulate one failed release.

**Done when:** CI blocks an intentional critical regression.

## Week 12

- Complete a system card, risk register, release approval checklist, and incident response exercise.
- Map at least one control to each NIST AI RMF function: Govern, Map, Measure, Manage.
- Record what requires human ownership rather than automation.

**Done when:** another reviewer can understand intended use, evidence, known limitations, owners, and release decision.

## Weekly reflection questions

1. What claim did I test?
2. What evidence supports or contradicts it?
3. What surprised me?
4. What is the largest remaining uncertainty?
5. What decision did I make?
6. What will I change next week?

## Scoring rubric

Score each category from 0–3:

| Category | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| Reproducibility | Cannot run | Runs with help | Documented run | Clean repeat confirmed |
| Evaluation | None | Anecdotal | Useful metrics | Metrics plus error analysis |
| Testing | None | Happy path | Core tests | Failure and regression tests |
| Documentation | Missing | Partial | Clear | Decision-ready |
| Safety | Ignored | Mentioned | Tested | Controlled and monitored |

A weekly score of 12/15 is a solid pass. Revisit any category scored 0.
