Simple curriculum

12 weeks, one concrete outcome each week

Aim for a small working artifact every week. Theory supports the build instead of replacing it.

Week 1 Reproducible experiments

See: hypothesis → experiment → evidence → decision.

Do: run the same benchmark twice.

Check: can someone else repeat it?

Week 2 Machine learning basics

See: data → features → model → prediction → metric.

Do: train a small text classifier.

Check: compare it with a simple baseline.

Week 3 Transformers + prompting

See: text → tokens → context → model → output.

Do: compare three prompt strategies.

Check: record accuracy, latency, and failure types.

Week 4 Embeddings + semantic search

See: document → chunks → vectors → similarity.

Do: create a tiny search index.

Check: does the right evidence appear in top results?

Week 5 RAG

See: question → retrieve → evidence → answer + citation.

Do: build an evidence-grounded Q&A pipeline.

Check: make unsupported answers fail safely.

Week 6 Agents + tools

See: request → route → tool → result → decision.

Do: add two read-only tools.

Check: require approval before simulated writes.

Week 7 Evaluation engineering

See: test case → expected behavior → score → gate.

Do: build an evaluation runner.

Check: decide what blocks a release.

Week 8 Observability + reliability

See: request → logs → traces → metrics → diagnosis.

Do: instrument your assistant.

Check: explain one failure from telemetry alone.

Week 9 AI security + red teaming

See: threat → attack path → control → test.

Do: create a safe red-team dataset.

Check: measure whether defenses actually help.

Week 10 APIs + Docker

See: client → API → AI pipeline → response.

Do: expose a FastAPI endpoint and containerize it.

Check: health check + tests pass.

Week 11 CI/CD + model operations

See: commit → tests → evals → build → release.

Do: create GitHub Actions gates.

Check: intentionally fail a gate, then fix it.

Week 12 Responsible AI governance

See: risk → owner → control → evidence → decision.

Do: create a system card + risk register.

Check: run a mock incident drill.

Do something now

Week 1: your first 45-minute lab

Mission

Prove that an experiment is only useful when you can reproduce it.

Teach-back check

Without notes, answer these out loud:

  • What was my hypothesis?
  • What did I keep the same?
  • What did I change?
  • What evidence did I collect?
  • Could another person reproduce it?

If you can explain those five things, you understand the core idea.
