01 / FOUNDATIONS

First, learn how information becomes a model output.

You do not start by memorizing transformer math. Start by watching information move through a simple system, then build one small piece yourself.

👀 SEE

Follow text → tokens → vectors → model → output.

🛠 BUILD

Train a tiny text classifier and save its exact run command.

🧪 BREAK

Change one variable: seed, data split, or feature method.

🔧 FIX

Make the experiment reproducible and compare against a baseline.

🧠 EXPLAIN

Teach back what changed and why the metric moved.

02 / AI SYSTEMS

Now connect the model to knowledge and tools.

The model is only one building. Retrieval, citations, tools, routing, and approval gates are the roads that make the whole city useful.

RAG

Plain English: look up useful evidence first, then let the model answer using that evidence.

Hands-on test: ask a question whose answer is not in the documents. Your app should say “I don’t have enough evidence” instead of guessing.

03 / QUALITY + SAFETY

Make failure visible before users find it for you.

Reliable AI is not “the demo looked good.” You need repeatable tests, traces, red-team cases, release gates, and an explanation for every important failure.

04 / PRODUCTION + GOVERNANCE

Ship the system like an engineer, govern it like it matters.

Containerize it. Test it. Gate releases. Track risk. Know who approves what. Keep evidence that explains why a version was allowed to ship.
