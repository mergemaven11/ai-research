# Research Areas

Each research area should contain a question, hypothesis, baseline, experiment design, metrics, results, and conclusions.

## Tracks

- `agents/` — tool use, planning, memory, orchestration, agent reliability
- `evaluation/` — benchmarks, hallucination checks, regressions, scoring
- `infrastructure/` — inference, containers, Kubernetes, observability, scaling
- `security/` — prompt injection, data boundaries, policy enforcement
- `multimodal/` — text/image/audio experiments
- `software-engineering/` — coding agents, debugging, testing, incident-response AI
